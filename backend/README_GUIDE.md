# README Folder Guide

The main README is the chronological engineering log.

Use this structure:

1. Project Objective
2. Overall Workflow
3. Project Architecture
4. V1 Engine
5. V1 Limitations
6. V1 Completion Record
7. V2 Engine
8. V2 Development Log
9. V2 Completion Record (add when V2 is actually complete)
10. V3 Engine
11. Continue the same pattern

Important:
- Do not rewrite old version history.
- Add new log entries below previous entries.
- Mark an engine as WORKING only after it has actually been tested.
- Keep future features under the appropriate future engine.
